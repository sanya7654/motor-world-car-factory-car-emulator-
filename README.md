# Motor World Car Factory — Car Atlas Renderer

A lightweight HTML5 renderer for viewing and previewing vehicles from **Motor World Car Factory** assets.

## ✨ Features

- 📁 **Select a folder** and automatically load the required vehicle data.
- 🚗 Detects and displays available cars from the selected game files.
- 🖼️ Supports vehicle atlases and their corresponding `.plist` data.
- 🔄 Wheel rotation preview.
- 🛞 Adjustable wheel rotation speed.
- 🛑 Brake animation support.
- 🌍 Automatically detects the browser/device language.
- 💻 Works directly in a modern web browser.
- 🚫 No installation or additional software required.

## 📂 Assets

The project now also includes an **`assets`** folder containing the required Motor World Car Factory assets.

This is useful for users who do not already have the necessary game assets available locally.

The included assets are provided so the renderer can be tested more easily without requiring every user to prepare the asset files manually.

> The renderer still supports loading assets from a selected folder.

## 🚀 How to use

1. Download the project.
2. Extract the ZIP archive.
3. Open `index.html` in a modern browser.
4. Click **Select Folder**.
5. Select the folder containing the Motor World Car Factory files.
6. The renderer will automatically search for the required vehicle data.
7. Select a vehicle and preview it.

## 🌐 Language

The interface automatically detects the browser/device language.

Currently supported languages include:

- 🇬🇧 English
- 🇷🇺 Russian
- 🇩🇪 German

If the detected language is not supported, English is used as the fallback language.

## 🛠️ Compatibility

Recommended browsers:

- Google Chrome
- Microsoft Edge
- Chromium-based browsers
- Yandex Browser

The browser must support the **File System Access API** for folder selection.
